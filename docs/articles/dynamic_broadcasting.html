Sync Sequential Random Walks Dashboard

Interactive Shiny dashboard for sequential random walk simulations with real-time visualization - runs in browser via WebR

Dashboard Comparison

This vignette provides a simplified, focused demonstration of synchronous random walks. For a comparison with the comprehensive dashboard:

This Dashboard (Sync Sequential): - Mode: Synchronous only (workers=0) - Scope: Single focused demo with essential controls - Target: Quick demonstration of basic functionality - Controls: Grid size, walkers, neighborhood, boundary - Visualization: Single real-time grid display - Best for: Understanding core random walk concepts

Comprehensive Dashboard (dashboard_comprehensive.html): - Mode: Both sync AND async parallel modes - Scope: Full-featured with all package capabilities - Target: Production-ready exploration tool - Controls: All parameters including worker processes, sync modes, max steps - Visualization: Multiple tabs (Grid, Histograms, Paths, Statistics, Telemetry) - Best for: In-depth analysis and performance comparison

server <- function(input, output, session) {

  # Reactive values for simulation state and history
  sim_result <- reactiveVal(NULL)
  sim_count <- reactiveVal(0)  # Count total simulations run
  sim_state <- reactiveVal("idle")  # States: idle, running, complete, error
  sim_start_time <- reactiveVal(NULL)
  sim_end_time <- reactiveVal(NULL)

  # Run simulation when button clicked
  observeEvent(input$run_sim, {
    # Update state to running
    sim_state("running")
    sim_start_time(Sys.time())
    sim_count(sim_count() + 1)

    output$status <- renderText({
      paste0(
        "🏃 SIMULATION RUNNING...\n",
        "Run #", sim_count(), "\n",
        "Grid: ", input$grid_size, "×", input$grid_size, "\n",
        "Walkers: ", input$n_walkers, "\n",
        "Workers: ", input$workers,
        if (input$workers > 0) " (async)" else " (sync)", "\n",
        "Started: ", format(sim_start_time(), "%H:%M:%S"), "\n",
        "Status: Processing..."
      )
    })

    tryCatch({
      start_time <- Sys.time()

      # Run simulation with async support
      result <- run_simulation(
        grid_size = input$grid_size,
        n_walkers = input$n_walkers,
        neighborhood = input$neighborhood,
        boundary = input$boundary,
        max_steps = input$max_steps,
        workers = input$workers,  # Auto-detects backend (mirai in WebR)
        sync_mode = "static",     # Grid snapshots (dynamic is Issue #130)
        verbose = FALSE,
        validate_percent = 0  # CRITICAL: Disable periodic validation (causes 100-1000x slowdown in WebR)
      )

      end_time <- Sys.time()
      elapsed <- as.numeric(difftime(end_time, start_time, units = "secs"))

      # Update state variables
      sim_state("complete")
      sim_end_time(end_time)
      sim_result(result)

      # Browser console logging for WebR diagnostics (Issue #157)
      message(sprintf("\n=== SIMULATION COMPLETE ==="))
      message(sprintf("Grid size: %dx%d", input$grid_size, input$grid_size))
      message(sprintf("Walkers: %d", input$n_walkers))
      message(sprintf("Black pixels: %d", sum(result$grid == 1)))
      message(sprintf("Elapsed time: %.2f seconds", elapsed))

      # NOTE: find_isolated_pixels() check removed due to performance impact
      # Even "once after simulation" was too slow in reactive context
      # See Issue #166 for async validation approach
      message(sprintf("==========================\n"))

      output$status <- renderText({
        stats <- result$statistics
        paste0(
          "✅ SIMULATION COMPLETE\n",
          "Run #", sim_count(), "\n",
          "━━━━━━━━━━━━━━━━━━━━━━\n",
          "Started:  ", format(sim_start_time(), "%H:%M:%S"), "\n",
          "Finished: ", format(sim_end_time(), "%H:%M:%S"), "\n",
          "Elapsed:  ", sprintf("%.2f", elapsed), " seconds\n",
          "━━━━━━━━━━━━━━━━━━━━━━\n",
          "Backend: ", if (input$workers > 0) "mirai" else "synchronous", "\n",
          "Black Pixels: ", stats$black_pixels,
          " (", sprintf("%.1f%%", stats$black_percentage), ")\n",
          "Walkers: ", input$n_walkers, " completed"
        )
      })

    }, error = function(e) {
      sim_state("error")
      sim_end_time(Sys.time())

      output$status <- renderText({
        paste0(
          "❌ SIMULATION ERROR\n",
          "Run #", sim_count(), "\n",
          "━━━━━━━━━━━━━━━━━━━━━━\n",
          "Error: ", e$message, "\n",
          "━━━━━━━━━━━━━━━━━━━━━━\n",
          "Check JavaScript console (F12) for details"
        )
      })
    })
  })

  # Grid plot
  output$grid_plot <- renderPlot({
    req(sim_result())
    result <- sim_result()

    # Defensive checks for WebR environment (Issue #157)
    req(!is.null(result$grid))
    req(nrow(result$grid) > 0)
    req(sum(result$grid == 1) > 0)  # Ensure has black pixels

    plot_grid(result, main = "Final Grid State")
  })

  # Walker paths plot
  output$paths_plot <- renderPlot({
    req(sim_result())
    result <- sim_result()
    n_walkers <- length(result$walkers)

    if (n_walkers >= 1) {
      first_n <- min(input$first_n_paths, n_walkers)
      last_n <- min(input$last_n_paths, n_walkers)

      # Select walker IDs: first N and last N
      walker_ids <- unique(c(
        if(first_n > 0) 1:first_n else NULL,
        if(last_n > 0) (n_walkers - last_n + 1):n_walkers else NULL
      ))

      if (length(walker_ids) > 0) {
        # Plot only selected walkers' paths
        filtered_walkers <- result$walkers[walker_ids]
        result_filtered <- result
        result_filtered$walkers <- filtered_walkers
        plot_walker_paths(result_filtered)
      } else {
        plot.new()
        text(0.5, 0.5, "No walkers selected")
      }
    } else {
      plot.new()
      text(0.5, 0.5, "No walkers available")
    }
  })

  # Distributions
  output$dist_overall <- renderPlot({
    req(sim_result())
    result <- sim_result()

    # Defensive check for walkers
    if (is.null(result$walkers) || length(result$walkers) == 0) {
      plot.new()
      text(0.5, 0.5, "Run a simulation first", cex = 1.5, col = "gray")
      return()
    }

    # Extract path lengths safely
    # NOTE: walker$path is a LIST, not a matrix - use walker$steps
    path_lengths <- tryCatch({
      sapply(result$walkers, function(w) {
        if (!is.null(w$steps)) w$steps else NA
      })
    }, error = function(e) numeric(0))

    path_lengths <- path_lengths[!is.na(path_lengths)]

    if (length(path_lengths) == 0) {
      plot.new()
      text(0.5, 0.5, "No path data available", cex = 1.5, col = "gray")
      return()
    }

    # Plot histogram
    hist(path_lengths,
         breaks = 30,
         col = "steelblue",
         border = "white",
         main = "Overall Path Length Distribution",
         xlab = "Path Length (steps)",
         ylab = "Frequency")
    abline(v = median(path_lengths), col = "red", lwd = 2, lty = 2)
    legend("topright",
           legend = c(paste("Median:", median(path_lengths)),
                     paste("Mean:", sprintf("%.1f", mean(path_lengths)))),
           col = c("red", "black"),
           lty = c(2, 1),
           lwd = 2)
  })

  output$dist_by_reason <- renderPlot({
    req(sim_result())
    result <- sim_result()

    # Defensive check for walkers
    if (is.null(result$walkers) || length(result$walkers) == 0) {
      plot.new()
      text(0.5, 0.5, "Run a simulation first", cex = 1.5, col = "gray")
      return()
    }

    # Extract data safely
    # NOTE: walker$path is a LIST, not a matrix - use walker$steps
    path_lengths <- tryCatch({
      sapply(result$walkers, function(w) {
        if (!is.null(w$steps)) w$steps else NA
      })
    }, error = function(e) numeric(0))

    reasons <- tryCatch({
      sapply(result$walkers, function(w) {
        if (!is.null(w$termination_reason)) w$termination_reason else "unknown"
      })
    }, error = function(e) character(0))

    # Remove NAs
    valid_idx <- !is.na(path_lengths)
    path_lengths <- path_lengths[valid_idx]
    reasons <- reasons[valid_idx]

    if (length(path_lengths) == 0 || length(reasons) == 0) {
      plot.new()
      text(0.5, 0.5, "No termination data available", cex = 1.5, col = "gray")
      return()
    }

    walkers_data <- data.frame(
      path_length = path_lengths,
      reason = reasons,
      stringsAsFactors = FALSE
    )

    # Plot boxplot by termination reason
    ggplot(walkers_data, aes(x = reason, y = path_length, fill = reason)) +
      geom_boxplot(alpha = 0.7) +
      geom_jitter(width = 0.2, alpha = 0.3) +
      labs(title = "Path Lengths by Termination Reason",
           x = "Termination Reason",
           y = "Path Length (steps)") +
      theme_minimal() +
      theme(legend.position = "none")
  })

  # Statistics text
  output$stats_text <- renderText({
    req(sim_result())
    stats <- sim_result()$statistics

    paste0(
      "Grid Size: ", stats$grid_size, "×", stats$grid_size, "\n",
      "Black Pixels: ", stats$black_pixels,
      sprintf(" (%.2f%%)\n", stats$black_percentage),
      "\nWalkers:\n",
      "  Total: ", stats$total_walkers, "\n",
      "  Completed: ", stats$completed_walkers, "\n",
      "\nSteps:\n",
      "  Total: ", stats$total_steps, "\n",
      "  Min: ", stats$min_steps, "\n",
      "  Max: ", stats$max_steps, "\n",
      "  Mean: ", sprintf("%.1f", stats$mean_steps), "\n",
      "  Median: ", stats$median_steps, "\n",
      "\nPerformance:\n",
      "  Elapsed Time: ", sprintf("%.2f", stats$elapsed_time_secs), "s\n",
      "\nTermination Reasons:\n",
      paste(sprintf("  %s: %d", names(stats$termination_reasons),
                    stats$termination_reasons), collapse = "\n")
    )
  })

  # Backend information with dynamic simulation data
  output$backend_info <- renderText({
    is_webr <- exists(".webr_env", envir = .GlobalEnv) ||
               identical(Sys.getenv("WEBR"), "1")

    # Static environment info
    env_info <- paste0(
      "=== ENVIRONMENT ===\n",
      "Runtime: ", if (is_webr) "WebR/Browser" else "Native R", "\n",
      "Mode: ", if (input$workers > 0) {
        if (is_webr) "mirai (not available - running sync sequential)" else "async parallel (crew)"
      } else {
        if (is_webr) "sync sequential (browser limitation)" else "sync sequential (workers=0)"
      }, "\n",
      "\n=== PACKAGE VERSIONS ===\n",
      "randomwalk: ", packageVersion("randomwalk"), "\n",
      if (requireNamespace("mirai", quietly = TRUE)) {
        paste0("mirai: ", packageVersion("mirai"), "\n")
      } else "",
      if (requireNamespace("nanonext", quietly = TRUE)) {
        paste0("nanonext: ", packageVersion("nanonext"), "\n")
      } else "",
      if (requireNamespace("crew", quietly = TRUE)) {
        paste0("crew: ", packageVersion("crew"), "\n")
      } else ""
    )

    # Dynamic simulation data (if available)
    result <- sim_result()
    if (is.null(result)) {
      paste0(
        env_info,
        "\n=== SIMULATION DATA ===\n",
        "No simulation run yet - click 'Run Simulation' to generate data\n",
        "\n=== STATUS ===\n",
        "State: ", sim_state(), "\n",
        "Total Runs: ", sim_count()
      )
    } else {
      stats <- result$statistics

      paste0(
        env_info,
        "\n=== SIMULATION DATA (Run #", sim_count(), ") ===\n",
        "State: ", sim_state(), "\n",
        if (!is.null(sim_start_time()) && !is.null(sim_end_time())) {
          paste0(
            "Started: ", format(sim_start_time(), "%H:%M:%S"), "\n",
            "Finished: ", format(sim_end_time(), "%H:%M:%S"), "\n",
            "Elapsed: ", sprintf("%.2f", as.numeric(difftime(sim_end_time(), sim_start_time(), units = "secs"))), " seconds\n"
          )
        } else "",
        "\n=== GRID STATE ===\n",
        "Size: ", stats$grid_size, "×", stats$grid_size, "\n",
        "Black Pixels: ", stats$black_pixels, " (", sprintf("%.1f%%", stats$black_percentage), ")\n",
        "White Pixels: ", stats$grid_size^2 - stats$black_pixels, " (", sprintf("%.1f%%", 100 - stats$black_percentage), ")\n",
        "\n=== WALKER STATISTICS ===\n",
        "Total: ", stats$total_walkers, "\n",
        "Completed: ", stats$completed_walkers, "\n",
        "Steps (Total): ", stats$total_steps, "\n",
        "Steps (Mean): ", sprintf("%.1f", stats$mean_steps), "\n",
        "Steps (Median): ", stats$median_steps, "\n",
        "Steps (Min): ", stats$min_steps, "\n",
        "Steps (Max): ", stats$max_steps, "\n",
        "\n=== TERMINATION REASONS ===\n",
        if (!is.null(stats$termination_reasons) && length(stats$termination_reasons) > 0) {
          paste(sprintf("%s: %d (%.1f%%)",
                        names(stats$termination_reasons),
                        stats$termination_reasons,
                        100 * stats$termination_reasons / stats$total_walkers),
                collapse = "\n")
        } else {
          "No data"
        },
        "\n=== PERFORMANCE ===\n",
        "Elapsed: ", sprintf("%.2f", stats$elapsed_time_secs), " seconds\n",
        "Steps/Second: ", sprintf("%.0f", stats$total_steps / max(stats$elapsed_time_secs, 0.001)), "\n"
      )
    }
  })

  # Package details
  output$package_details <- renderText({
    paste0(
      "=== PACKAGE SOURCES ===\n\n",
      "randomwalk:\n",
      "  https://johngavin.github.io/randomwalk/\n\n",
      "WebR packages (NOT installed - parallel processing disabled):\n",
      "  nanonext & mirai: https://r-lib.r-universe.dev\n",
      "  Note: Not compatible with WebR - causes browser version to run sync sequential\n\n",
      "=== PROCESSING MODES ===\n\n",
      "THIS BROWSER VERSION (WebR):\n",
      "  - Sync Sequential Mode (workers=0)\n",
      "  - Processes one walker at a time sequentially\n",
      "  - No parallel processing available\n",
      "  - All computation happens client-side in browser\n\n",
      "R CODE OUTSIDE WEBPAGE (Native R):\n",
      "  - Async Parallel Mode (workers=2+)\n",
      "  - Uses crew backend for async parallelization\n",
      "  - crew internally uses mirai for parallel processing\n",
      "  - Can process multiple walkers simultaneously\n",
      "  - Full async/parallel capabilities when running randomwalk package\n",
      "    in regular R (not in browser)\n\n",
      "=== SYNC MODES (Both Environments) ===\n\n",
      "sync_mode='static' (current):\n",
      "  - Workers get grid snapshots\n",
      "  - Used in native R async parallel mode\n",
      "  - Not applicable in browser (no workers)\n\n",
      "sync_mode='dynamic' (future):\n",
      "  - Real-time broadcasting via nanonext\n",
      "  - Issue #130 - future work\n",
      "  - Would require nanonext WebR compatibility"
    )
  })
}

Sync Sequential Random Walks

This vignette provides a fully interactive Shiny application for sync sequential random walk simulations running directly in your browser using WebAssembly.

Important: This browser-based dashboard runs in sync sequential mode (no parallel processing):

  • WebR/Browser: Sync sequential mode only (workers=0) - processes one walker at a time
  • Native R (outside webpage): The randomwalk package supports async parallel processing with crew backend (workers=2+) when run in regular R

The WebR limitation is due to mirai/nanonext compatibility issues in WebAssembly (tracked in Issue #158). The dashboard is fully functional for visualizing random walk dynamics in the browser.

Features

This dashboard demonstrates:

  1. Browser-based Simulation: Runs entirely in your browser via WebAssembly (no server required)
  2. Real-time Visualization: Grid state, walker paths, and statistics
  3. Parameter Tuning: Adjust grid size, walkers, boundaries interactively
  4. Path Filtering: View first N and/or last N walker paths (Details page for technical info)

Notes

  • This Browser Version: Sync sequential mode (workers=0) - processes walkers one at a time
  • R Code Outside Webpage: Full async parallel support with crew backend (workers=2+) when running randomwalk package in native R
  • See Details tab in the app for technical information about implementation differences

Try It Yourself

Experiment with different parameters:

  • Larger grid: More exploration space (try 30 or 40)
  • More walkers: Increase density (try 10 or 15)
  • Path filters: Adjust first_n/last_n sliders on Walker Paths tab
  • 8-hood: Enable diagonal movement for more path options
  • Wrap boundary: Toroidal grid (no boundaries)

Note: Keep workers=0 in WebR mode
