The Problem

Currently, async workers receive a frozen copy of the grid that never updates:

Show code 
# Current: Static snapshot
controller$push(
  command = simulate_walker(...),
  data = list(
    walker_id = i,
    grid_state = grid  # FROZEN - never updates!
  )
)

Consequences: - ✅ Simple and fast - ❌ Workers don’t see each other’s movements - ❌ No collision detection - ❌ Different behavior from sync mode

The Solution

Workers communicate via publish-subscribe pattern:

Show code 
# New: Dynamic broadcasting
# Worker 1 creates black pixel → broadcasts to all workers
broadcast_black_pixel(pub_socket, position, walker_id)

# Worker 2-4 receive and apply update
local_grid <- update_grid_from_broadcasts(sub_socket, local_grid)

Key Insight: Minimal Broadcasting

Only broadcast when NEW black pixel is created!

Event Broadcast? Why
Walker detects black neighbor ✅ YES Creates new black pixel
Started on black ❌ NO Already broadcast earlier
Max steps reached ❌ NO No pixel created
Hit boundary ❌ NO No pixel created

Result: ~10-20 broadcasts per simulation (not 10,000!) 🎯

Architecture

``` ┌────────────────────────────────────────────┐ │ Main Process │ │ ├─ Publisher Socket (nanonext) │ │ └─ Crew Controller │ └────────────────────────────────────────────┘ │ │ pub/sub (nanonext NNG) │ ┌─────────┴──────┬──────────┬──────────┐ │ │ │ │ ┌───▼───┐ ┌──────▼──┐ ┌────▼────┐ ┌─▼──┐ │Worker1│ │Worker 2 │ │Worker 3 │ │… │ │Local │ │Local │ │Local │ │ │ │Grid │ │Grid │ │Grid │ │ │ │Sub │ │Sub │ │Sub │ │ │ └───────┘ └─────────┘ └─────────┘ └────┘ ```

Walker Logic (Simplified)

The complete walker logic with Step 2 removed for simplicity:

Show code 
simulate_walker_dynamic <- function(walker_id, initial_grid,
                                   pub_socket, sub_socket, ...) {
  local_grid <- initial_grid

  # ═══════════════════════════════════════════════════════
  # STEP 0: Check starting position (before loop)
  # ═══════════════════════════════════════════════════════
  position <- sample_start_position(grid_size)

  if (local_grid[position[1], position[2]] == "black") {
    return(list(status = "started_on_black", steps = 0))
    # ❌ NO BROADCAST - pixel already broadcast earlier
  }

  # ═══════════════════════════════════════════════════════
  # MAIN LOOP (Steps 1-N)
  # ═══════════════════════════════════════════════════════
  for (step in 1:max_steps) {

    # ─────────────────────────────────────────────────────
    # STEP 1: Pop ALL broadcasts, update local grid
    # ─────────────────────────────────────────────────────
    while (has_messages(sub_socket)) {
      msg <- pop_message(sub_socket)
      local_grid[msg$position[1], msg$position[2]] <- "black"
    }

    # ─────────────────────────────────────────────────────
    # STEP 2: Check neighbors for black pixels
    # ─────────────────────────────────────────────────────
    neighbors <- get_neighbors(position, neighborhood)
    has_black_neighbor <- any(is_black(neighbors, local_grid))

    if (has_black_neighbor) {
      # Current position becomes BLACK
      local_grid[position[1], position[2]] <- "black"

      # ✅ BROADCAST to all workers
      broadcast_black_pixel(pub_socket, position, walker_id)

      return(list(status = "black_neighbor_detected", steps = step))
    }

    # ─────────────────────────────────────────────────────
    # STEP 3: Make move
    # ─────────────────────────────────────────────────────
    next_position <- choose_next_position(position, local_grid)

    if (is_boundary(next_position, grid_size)) {
      if (boundary == "terminate") {
        return(list(status = "boundary", steps = step))
        # ❌ NO BROADCAST
      }
      next_position <- handle_boundary(next_position, boundary)
    }

    position <- next_position
  }

  # Max steps - walker stops (no black pixel)
  return(list(status = "max_steps", steps = max_steps))
  # ❌ NO BROADCAST
}

Broadcasting Functions

Core infrastructure (implemented in R/broadcasting.R):

Show code 
library(nanonext)

# Initialize publisher (main process)
pub_socket <- init_publisher_socket(port = 5555)

# Initialize subscriber (each worker)
sub_socket <- init_subscriber_socket(host = "localhost", port = 5555)

# Broadcast black pixel
broadcast_black_pixel(pub_socket, c(50, 50), walker_id = 1)

# Update local grid from all pending broadcasts
local_grid <- update_grid_from_broadcasts(sub_socket, local_grid)

# Cleanup
close_sockets(pub_socket, sub_socket)

Eventual Consistency

Philosophy: “This is a simulation, not a bank”

Show code 
# Workers use best-efforts synchronization
for (step in 1:max_steps) {
  # 1. Pop ALL pending messages
  local_grid <- update_grid_from_broadcasts(sub_socket, local_grid)

  # 2. Make move with current state (might be slightly stale)
  position <- make_move(position, local_grid)

  # 3. Broadcast if black pixel created
  if (created_black_pixel) {
    broadcast_black_pixel(pub_socket, position)
  }

  # 4. Any staleness resolves on next iteration
}

Acceptable trade-offs: - ⚠️ Worker might have stale state for 1 iteration - ⚠️ Possible duplicate broadcast (rare) - ✅ System remains stable - ✅ Eventually consistent

# Performance comparison
compare_performance <- function(static_result, dynamic_result) {
  tibble(
    metric = c(
      "Black pixels",
      "Total steps",
      "Elapsed time (s)",
      "Steps per second",
      "Collisions detected",
      "Overhead (%)"
    ),
    static = c(
      static_result$statistics$black_pixels,
      static_result$statistics$total_steps,
      static_result$statistics$elapsed_time_secs,
      static_result$statistics$total_steps / static_result$statistics$elapsed_time_secs,
      0,  # No collisions in static mode
      0
    ),
    dynamic = c(
      dynamic_result$statistics$black_pixels,
      dynamic_result$statistics$total_steps,
      dynamic_result$statistics$elapsed_time_secs,
      dynamic_result$statistics$total_steps / dynamic_result$statistics$elapsed_time_secs,
      sum(dynamic_result$statistics$termination_reasons == "black_neighbor_detected"),
      ((dynamic_result$statistics$elapsed_time_secs /
        static_result$statistics$elapsed_time_secs) - 1) * 100
    )
  )
}

# Run comparison

analyze_clustering <- function(grid) {
  # Convert grid to point pattern
  black_positions <- which(grid == "black", arr.ind = TRUE)

  ppp_data <- ppp(
    x = black_positions[, 2],
    y = black_positions[, 1],
    window = owin(c(1, ncol(grid)), c(1, nrow(grid)))
  )

  # Calculate Ripley's K function
  k_func <- Kest(ppp_data)

  # Plot
  plot(k_func, main = "Clustering Analysis")
}

Use Dynamic Mode When

Summary

Dynamic broadcasting enables realistic walker interactions in async simulations:

✅ Minimal overhead - Only ~10-20 broadcasts per simulation ✅ Eventual consistency - Best-efforts approach, not perfect sync ✅ Simple protocol - Pop messages, check neighbors, broadcast ✅ Robust - Handles race conditions through repeated updates

Key insight: Workers only care about obstacles (black pixels), not walker positions. This makes the implementation dramatically simpler and more efficient.
