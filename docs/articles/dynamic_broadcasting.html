Async Parallel Random Walks

This vignette provides a fully interactive Shiny application demonstrating async parallel random walk simulations running directly in your browser using WebAssembly.

Note: This demonstrates async/parallel random walk simulations. The randomwalk package auto-detects your environment and selects the appropriate backend:

  • WebR/Browser: Currently runs in synchronous mode (workers=1) due to mirai/nanonext compatibility issues in WebAssembly
  • Native R: Uses crew backend with full async support (workers=2)

The WebR async limitation is tracked in Issue #158. The dashboard is fully functional in the browser, just without parallel processing.

# Shiny Server
# ============================================================================

server <- function(input, output, session) {

  # Reactive value to store simulation result
  sim_result <- reactiveVal(NULL)

  # Run simulation when button clicked
  observeEvent(input$run_sim, {
    output$status <- renderText({
      paste0(
        "Running simulation...\n",
        "Grid: ", input$grid_size, "×", input$grid_size, "\n",
        "Walkers: ", input$n_walkers, "\n",
        "Workers: ", input$workers,
        if (input$workers > 0) " (async)" else " (sync)"
      )
    })

    tryCatch({
      # Run simulation with async support
      result <- run_simulation(
        grid_size = input$grid_size,
        n_walkers = input$n_walkers,
        neighborhood = input$neighborhood,
        boundary = input$boundary,
        max_steps = input$max_steps,
        workers = input$workers,  # Auto-detects backend (mirai in WebR)
        sync_mode = "static",     # Grid snapshots (dynamic is Issue #130)
        verbose = FALSE
      )

      sim_result(result)

      output$status <- renderText({
        paste0(
          "✅ Simulation complete!\n",
          "Elapsed time: ", sprintf("%.2f", result$statistics$elapsed_time_secs), "s\n",
          "Backend: ", if (input$workers > 0) "mirai" else "synchronous"
        )
      })

    }, error = function(e) {
      output$status <- renderText({
        paste0("❌ ERROR:\n", e$message)
      })
    })
  })

  # Grid plot
  output$grid_plot <- renderPlot({
    req(sim_result())
    plot_grid(sim_result(), main = "Final Grid State")
  })

  # Walker paths plot
  output$paths_plot <- renderPlot({
    req(sim_result())
    plot_walker_paths(sim_result())
  })

  # Statistics text
  output$stats_text <- renderText({
    req(sim_result())
    stats <- sim_result()$statistics

    paste0(
      "Grid Size: ", stats$grid_size, "×", stats$grid_size, "\n",
      "Black Pixels: ", stats$black_pixels,
      sprintf(" (%.2f%%)\n", stats$black_percentage),
      "\nWalkers:\n",
      "  Total: ", stats$total_walkers, "\n",
      "  Completed: ", stats$completed_walkers, "\n",
      "\nSteps:\n",
      "  Total: ", stats$total_steps, "\n",
      "  Min: ", stats$min_steps, "\n",
      "  Max: ", stats$max_steps, "\n",
      "  Mean: ", sprintf("%.1f", stats$mean_steps), "\n",
      "  Median: ", stats$median_steps, "\n",
      "\nPerformance:\n",
      "  Elapsed Time: ", sprintf("%.2f", stats$elapsed_time_secs), "s\n",
      "\nTermination Reasons:\n",
      paste(sprintf("  %s: %d", names(stats$termination_reasons),
                    stats$termination_reasons), collapse = "\n")
    )
  })

  # Backend information
  output$backend_info <- renderText({
    is_webr <- exists(".webr_env", envir = .GlobalEnv) ||
               identical(Sys.getenv("WEBR"), "1")

    paste0(
      "Environment: ", if (is_webr) "WebR/Browser" else "Native R", "\n",
      "Backend: ", if (input$workers > 0) {
        if (is_webr) "mirai (WebAssembly-compatible)" else "crew"
      } else {
        "synchronous (no parallelization)"
      }, "\n",
      "\nPackage Versions:\n",
      "  randomwalk: ", packageVersion("randomwalk"), "\n",
      if (requireNamespace("mirai", quietly = TRUE)) {
        paste0("  mirai: ", packageVersion("mirai"), "\n")
      } else "",
      if (requireNamespace("nanonext", quietly = TRUE)) {
        paste0("  nanonext: ", packageVersion("nanonext"), "\n")
      } else "",
      if (requireNamespace("crew", quietly = TRUE)) {
        paste0("  crew: ", packageVersion("crew"), "\n")
      } else "",
      "\nIssue #129: ✅ Async parallel support in WebAssembly\n",
      "Issue #130: ⏳ Dynamic broadcasting (future work)"
    )
  })
}

# ============================================================================
# Run Shiny App
# ============================================================================

shinyApp(ui = ui, server = server)

Features

This dashboard demonstrates:

  1. Auto-backend Selection: Automatically uses mirai in WebR, crew in native R
  2. True Async Parallelization: Workers > 0 enables parallel processing in browser!
  3. Real-time Visualization: Grid state, walker paths, and statistics
  4. Parameter Tuning: Adjust simulation parameters interactively

Technical Details

Package Sources

  • randomwalk: https://johngavin.github.io/randomwalk/
  • nanonext & mirai: https://r-lib.r-universe.dev

Backend Selection (Issue #129 ✅)

In WebR/Browser: - Uses mirai backend for async parallelization - nanonext package from r-lib.r-universe.dev - All computation happens client-side

In Native R: - Uses crew backend (preferred for better abstractions) - crew internally uses mirai

Sync Modes

  • sync_mode="static": Workers get grid snapshots (current, used in WebR)
  • sync_mode="dynamic": Real-time broadcasting via nanonext (Issue #130, future work)

Try It Yourself

Experiment with different parameters:

  • Larger grid: More exploration space (try 30 or 40)
  • More walkers: Increase density (try 10 or 15)
  • More workers: Increase parallelization (try 4)
  • 8-hood: Enable diagonal movement
  • Wrap boundary: Toroidal grid (no boundaries)
