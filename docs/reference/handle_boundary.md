# Handle Boundary Condition

Handle Boundary Condition

## Usage

``` r
handle_boundary(position, boundary, nrow, ncol)
```

## Arguments

- position:

  Vector c(x, y) position that hit boundary

- boundary:

  Character "wrap" or "terminate"

- nrow:

  Integer grid rows

- ncol:

  Integer grid columns

## Value

Vector c(x, y) adjusted position
